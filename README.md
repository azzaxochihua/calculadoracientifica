Calculadora Científica – Python & Tkinter

Este proyecto es una calculadora científica desarrollada en Python, utilizando la librería Tkinter para la interfaz gráfica.
Permite realizar operaciones matemáticas básicas y avanzadas como potencias, raíces, funciones trigonométricas, logaritmos, constantes matemáticas y más.

 Descripción General

La calculadora incluye:

Operaciones básicas: suma, resta, multiplicación, división.

Funciones científicas:
sin, cos, tan, asin, acos, atan, sqrt, exp, ln, etc.

Soporte para paréntesis.

Uso de constantes matemáticas (pi, e).

Botón para borrar y retroceso.

Evaluación segura mediante un conjunto limitado de funciones permitidas.
